### 📋 Professional Summary

Final-year **BS Information Technology** student, aspiring toward a career in **Security Operations and Detection Engineering**. I build complete, evidence-driven security pipelines — from log ingestion in Splunk to AI-generated threat assessments that are validated against raw artifacts before being trusted. My portfolio favors depth over breadth: every project is built to hold up in a technical interview, not just to fill a repo list.

Hands-on experience spans **SIEM engineering (Splunk Enterprise + Sysmon)**, **honeypot-based adversary research (Cowrie)**, **detection lifecycle validation with Atomic Red Team**, and **network/web-layer security tooling (Wireshark, Burp Suite, Nmap, CyberChef)** — all practiced in a self-built lab running Kali Linux and Ubuntu alongside Windows-based log collection.
